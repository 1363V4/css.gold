why gold???

the important part

"gold" because the design is modular and based on the golden ratio

...what?

  • - we define a variable "m" equal to 1rem
  • - we then define "l", 60% bigger
  • - then "xl", 60% bigger than "l"
  • - and so on...

this has 3 main benefits:

- you can reuse it anywhere in your css

- if you change var(--m), everything changes

- it's damn easy to understand

div#gold {padding: var(--xl)}
